# seikkailupeli

**Simo Nuorala**

 Pelin ideana on kerätä 7 x 7 ruudukolta roskia, ja viedä ne lopuksi roskiin. 
 Tasoja pelissä on 3, ja tasoissa on eri määrä roskia, 1. tasossa on 3, 2. tasossa on 4, ja tasossa 3. on 5.
 Jokaisessa tasossa pitää kerätä vähintään 2 roskaa, jotta voi edetä seuraavalle tasolle.
 jokainen roska antaa yhden pisteen, joten maksimi pisteet pelissä on 12 pistettä.
